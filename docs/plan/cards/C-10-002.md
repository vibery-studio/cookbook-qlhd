## Context
SPEC-10 §3.2 (7 bước) nguyên văn; DEC-1 B, DEC-3, DEC-7, DEC-9; PLAN-10 §0 P-5/P-6/P-12, §2b (mã cảnh báo cố định), R-4 (tùy chọn parser), R-5 (bomb), R-6 (CPU).
Thư viện (npm 2026-10-01, đọc lại README chính thức trước khi cài): `fflate` 0.8.3, `fast-xml-parser` 5.11.2. Cài: `pnpm --filter @runway/api add fflate@0.8.3 fast-xml-parser@5.11.2 --store-dir .pnpm-store/v10`; ghim chính xác (bỏ `^`).
Domain thuần: không import Hono/DB/env. `template-check.ts` CHỈ thêm `export` cho `fold`, `INTERNAL_NOTE_PHRASES` (R-3) — converter dùng chung, không chép.
- unzip: 4 byte `PK\x03\x04` không có → `not_docx`. Đọc EOCD đếm mục > 1000 → `too_many_entries` (trước khi giải nén). `unzipSync` lỗi → `not_docx`. `filter` chỉ nhận `[Content_Types].xml`, `word/document.xml`, `word/_rels/document.xml.rels`, `word/header*.xml`, `word/footer*.xml`, ghi nhận tên `word/vbaProject.bin` (không giải nén). `originalSize` > 2 MB hoặc 0 với `compressedSize` > 0 → `too_large_inflated`; giải nén bằng `Inflate` luồng, đếm byte thật, cắt ở 2 MB tổng (fixture `bomb-lying.docx`).
- content types: main `macroEnabled` hoặc có `vbaProject.bin` → `macro_enabled`; không có main `wordprocessingml.document.main+xml` → `not_docx`; thiếu `word/document.xml` → `no_document`.
- XML: `<!DOCTYPE` (không phân biệt hoa thường) → `xml_invalid`; `XMLParser({preserveOrder:true, ignoreAttributes:false, processEntities:false, trimValues:false, parseTagValue:false, parseAttributeValue:false})`; `XMLValidator.validate` sai → `xml_invalid`; tự giải mã `&lt; &gt; &amp; &quot; &apos; &#N; &#xH;`.
- walk: §3.2 bước 4 (Title/Heading1→h1, Heading2→h2, Heading3–9→h3; jc center/right/end; run b/i gộp; br (page → bỏ + cảnh báo), tab → " "; numPr liền nhau → ul/li; tbl/tr/tc, gridSpan/vMerge/bảng lồng làm phẳng; hyperlink/sdt/smartTag/ins lấy nội dung; del/instrText/drawing/pict/object/txbxContent/footnoteReference/commentReference/altChunk bỏ + cảnh báo). Mọi chữ escape `& < > "`. Header/footer: chỉ dò `{{` → `header_footer_placeholder`, không thì `header_footer_dropped`.
- placeholders: ghép chữ cả đoạn/ô rồi quét `\{\{([\s\S]*?)\}\}`; `#if k`/`/if` giữ; slug theo DEC-3; slug null → giữ nguyên chữ; chèn lại `{{key}}` trơn, ngoài mọi `<strong>/<em>` (định dạng run quanh placeholder tách ra trước/sau). Đoạn trùng `INTERNAL_NOTE_PHRASES` (so `fold`) → `removed[]`. `linesTable` = index trong mọi `w:tbl` cấp 1 → thay bảng bằng `<p>{{bang_hang}}</p>`, bỏ key chỉ nằm trong bảng đó, thêm `bang_hang`; index ngoài tầm → bỏ qua.
- Hàm không bao giờ ném: bọc try/catch ở `index.ts` → `{error:"xml_invalid"}` cho lỗi parse.
- Bench (`scripts/bench-docx-import.ts`, `pnpm tsx`): đọc 3 file box từ `apps/api/test/fixtures/docx/`, 50 vòng mỗi file sau 10 vòng làm nóng, in trung vị/p95 ms.
