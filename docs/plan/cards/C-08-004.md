# C-08-004 · API sản phẩm & giá

## Goal
`/products*` chạy đúng PLAN-08 §2b; không đường nào sửa/xóa mức đã hiệu lực hay lùi ngày, kể cả khi đua.

## Context
SPEC-08 FR-1/2/3/8, DEC-1/5/6/11, §4 (Input, Duplicates, Two people, Failure, Permissions, Time), §5. PLAN-08 §2b (thứ tự lỗi, audit, P-3, P-6). RUNWAY: route giữ `c`; service nhận `(deps, actor, input, now)`; DAO thuần `(db, input) → DTO`; ghi = MỘT `db.batch` (thay đổi + audit); PATCH: `UPDATE … WHERE id=? AND version=? RETURNING` (0 dòng → đọc lại: 404 hay `stale`); audit có điều kiện cùng batch (mẫu `role-write-dao.ts`: stmt audit `INSERT … SELECT … WHERE` cùng guard, CAS cuối). Thêm mức: INSERT thẳng — UNIQUE → 409 `duplicate`; RAISE "backdated" → 422 `price-backdated`; kiểm "≥ mai khi đã có mức / ≥ hôm nay khi là mức đầu" ở service bằng `todayInVN(now)` TRƯỚC để trả lỗi rõ (trigger là lớp 2). Hủy: `DELETE … WHERE id=? AND product_id=? AND effective_from > today RETURNING` + audit cùng guard; 0 dòng → tồn tại? `price-in-effect` : 404; RAISE → 409 `price-in-effect`. `first_price` thiếu `price:write` → 403 + `permission.denied` (`permission: "price:write"`). Giá/ngày đọc: `levelAt`/`withEffectiveTo`/`levelStatus`/`unitPriceIncVat` của 002 (không viết lại). `code_norm` = trim + upper. Tìm `q`: `code_norm LIKE` hoặc tên (lower). Audit target `product:<id>`; metadata không PII: `product.created {code, kind}` · `product.updated {code, fields}` · `product.deactivated|reactivated {code}` · `price.added|cancelled {code, effective_from, unit_price_ex_vat, vat_rate_bps}`. Trần 500 (P-6): INSERT … WHERE (SELECT COUNT(*) FROM products) < 500. **Không đổi OpenAPI.**
