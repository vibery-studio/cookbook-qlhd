# C-04b-001c · API — xóa nháp

## Goal
`DELETE /contracts/{id}`: người tạo xóa cứng hợp đồng `draft` (204); audit `contract.deleted` chỉ `{id}`.

## Context
SPEC-04b §3.2 (E)(F), FR-20, §5 (hard delete PII), R-6. Guard `contract:write` + người tạo (403 `creator_only` + `permission.denied`). `db.batch`: (1) audit `contract.deleted` `INSERT … SELECT … FROM contracts WHERE id AND status='draft' AND created_by=:actor`, metadata **chỉ `{id}`**, target `contract:<id>` · (2) `UPDATE contracts SET replaced_by_id=NULL WHERE replaced_by_id=:id` · (3) `DELETE FROM approval_steps WHERE contract_id=:id` · (4) `DELETE FROM contracts WHERE id AND status='draft' AND created_by=:actor`. 0 dòng → đọc lại: không tồn tại → 404, khác draft → 409 `state-conflict` (`current_status`). `GET /contracts/{id}/audit` của hợp đồng đã xóa → 404. Dãy số không bị đụng (nháp chưa có seq). Hằng `contract.deleted` vào `CONTRACT_ACTIONS`. `docs/privacy.md`: thêm mục hợp đồng — `snapshot` chứa SĐT/email/MST/địa chỉ khách; xóa nháp = xóa cứng; audit chỉ id; kiểm `grep contract_id apps/api/src/db/schema.ts` chỉ còn `approval_steps` + `replaced_by_id`. Không sửa `apps/api/test/integration/contracts-4b-acceptance.test.ts`, `contracts-acceptance.test.ts`. Ghi nhớ: route giữ `c`, service không thấy `c`, DAO thuần `(db, input) → DTO`, race bằng CAS + `db.batch`, lỗi Problem+JSON. Xong thì `pnpm openapi:export && pnpm client:generate` cùng commit.
