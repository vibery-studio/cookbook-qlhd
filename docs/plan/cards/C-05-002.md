# C-05-002 · Job PDF

## Goal
Sau phát hành, PDF được tạo một lần (renderer thật = Chrome của Cloudflare), lưu R2, ghi `pdf_*` + audit trong một batch; lỗi thì thử lại rồi `failed`; cron bù.

## Context
SPEC-05 FR-1..FR-4 FR-7, §3.2 (luồng chi tiết — làm đúng như ghi). Chữ ký mà test gọi (KHÔNG đổi): 
- `contractPdfConsumer(batch: MessageBatch<{contract_id:string}>, env: Bindings, deps?: { renderer?: PdfRenderer })` — `deps.renderer` có thì dùng nó (kể cả khi `PDF_RENDERER=off`); không có + `off` → ack hết, log `contract.pdf.disabled`.
- `contractPdfSweeper(deps: { db: Db; queue: Queue<{contract_id:string}>; now: number /* unix s */ })` — dùng `queue.sendBatch([{ body: { contract_id } }])`, chỉ gọi khi có việc.
- Retry: `msg.attempts < 3` → `msg.retry({ delaySeconds: 30 * msg.attempts })`; `>= 3` → ghi lỗi (`pdf_attempts+1`, `pdf_failed_at=now`) rồi `msg.ack()`.
- Audit `contract.pdf_generated`, actor `null`, target id, metadata đúng `{ size }`.
Rules: DAO thuần `(db, input)`; CAS `UPDATE … WHERE pdf_key IS NULL AND status IN ('issued','voided') RETURNING` + `auditInsert` trong `db.batch` (lưu ý: `db.batch` với update-returning — xem cách `contract-issue-dao.ts` làm); CAS thua → `FILES.delete(key)`. Khóa R2 `contracts/{id}/{generateUlid()}.pdf`, `httpMetadata.contentType="application/pdf"`. Log không PII (id, size, ms, error message). `issueContract(db, ctx, id, deps?: { pdfQueue?: Queue<…> })` gửi sau khi render (try/catch log `contract.pdf.enqueue_failed`). `index.ts`: `queue()` dispatch theo `batch.queue` (`email-retry` giữ nguyên); cron `*/5` chạy thêm sweeper khi `PDF_RENDERER !== "off"`.
Adapter `pdf-browser.ts`: `@cloudflare/puppeteer` — `launch(env.BROWSER)` → `newPage` → `setContent(html,{waitUntil:"load"})` → `addStyleTag({content: fontCss()})` → `evaluate(() => document.fonts.ready)` → `pdf({format:"A4", preferCSSPageSize:true, printBackground:true, displayHeaderFooter:false, timeout:30000})` → `browser.close()` trong `finally`. Mẫu đã chạy thật: `/tmp/pdfspike/src/index.ts`.
Fonts: copy 6 file `arimo-{latin,latin-ext,vietnamese}-{400,700}-normal.woff2` + `LICENSE` từ `/tmp/pdfspike/node_modules/@fontsource/arimo/` vào `src/assets/fonts/`; `fontCss()` dựng `@font-face{font-family:"Arial";…unicode-range}` một lần/isolate (unicode-range lấy từ file css `latin-400.css`, `latin-ext-400.css`, `vietnamese-400.css` của fontsource). Khai báo module `*.woff2` → `ArrayBuffer`.
