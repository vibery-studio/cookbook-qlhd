## Context

- Route (thay 501): `contract:read` + `withIdempotency()` đã gắn (002); route truyền perms; service trả `forbidden` → route ghi `permission.denied {permission: WRITE_PERM[type]}` + 403.
- Service: đọc cha (404) → `CHILD_OF[parent.type]` chứa `type`? (không → `child-type`) → quyền → `values.giam_gia` (→ `lines-locked`) → mẫu (`template_id` hoặc mẫu seed của loại con; khác loại → `template-type`) → khách (snapshot cha `customer_id`) → `buildChildSnapshot` (004: DEC-7 `validation` `lines`, `nothing-to-pay`, `missing-fields` qua mẫu) — chẩn đoán cha chưa issued/quá hạn CHẠY TRƯỚC khi dựng (đọc), nhưng guard thật là CAS.
- DAO `createChildCas(db, {row, today, audit})` = `db.batch([INSERT INTO contracts … SELECT … WHERE EXISTS (SELECT 1 FROM contracts p WHERE p.id = :parent AND p.status='issued' AND (p.type <> 'quote' OR p.valid_until >= :today)), INSERT audit … SELECT … WHERE changes() = 1])`; UNIQUE live → bắt lỗi → đọc `existing_id` → 409 `child-exists`; 0 dòng → đọc lại cha → 409 `parent-not-issued`/`quote-expired`. Audit `contract.created {to:"draft", type, parent_id, parent_number}` (không PII). Mẫu theo `contract-write-dao.ts:219-253` (copy) — KHÔNG sửa file đó (006 sở hữu), viết DAO riêng.
- Con không thừa hưởng duyệt (I5): submit dùng `approval_policy` của phiên bản mẫu con + `snapshot.discount_bps` đóng băng → 15% vẫn có "Giám đốc duyệt" (không code thêm).
