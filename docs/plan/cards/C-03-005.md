# C-03-005 · Read side

## Goal
Team-wide reading: `GET /contracts` (one query per page + counts), `GET /contracts/{id}` (steps, timeline, `can`), `GET /approvals/mine`
(one join), `GET /contracts/{id}/audit` (reuse `listAudit` with target `contract:<id>`).

## Context
SPEC-03 FR-9, §3.4 (timeline from time columns + `approval_steps`, readable without `audit:read`), §3.5 rows, workbook §5 (no N+1: `customer_name`
and `total` are columns copied from the snapshot) and §9 "Copying the list example verbatim" (write the filter you mean). Queue eligibility
(I9 + SoD): step is the lowest `waiting` of a `pending` contract; caller has the step's permission via an active role (+ `required_role` if set);
caller ≠ `created_by`; caller has not decided any step of that contract. Must agree with domain `isEligible` (PLAN risk 5).

## Scope
In: `contract-read-dao.ts`: `listContracts(db, {status?, customerId?, createdBy?, after?, limit})` ordered `(updated_at DESC, id DESC)` with
`created_by_name` join; `countByStatus(db, filters sans status)`; `getContractDetail(db, id)` (contract + steps ordered by step_no + creator name);
`listApprovalQueue(db, {actorId, after?, limit})`. `read-service.ts`: cursor encode/decode (bad cursor → invalid), timeline build
(`created_at` → created, `submitted_at`, each step decision, `issued_at`, `voided_at`), `can` flags for the caller (edit/submit: creator + draft;
approve/reject: `isEligible` on the current step + not decided; issue: `contract:issue` + approved; void: `contract:issue` + issued;
copy: `contract:write` + rejected, or voided without `replaced_by_id`), `contractAudit` → `listAudit` (404 when the contract doesn't exist).
Out: writes; routes.
