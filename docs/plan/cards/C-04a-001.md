- Research official docs (2026-09-29):
  - Cloudflare [static-assets binding](https://developers.cloudflare.com/workers/static-assets/binding/) xác nhận `run_worker_first` nhận boolean hoặc glob array; `*` là wildcard, và `/customers/*` không match `/customers` vì dấu `/` trước wildcard, nên giữ cả hai pattern. [SPA routing](https://developers.cloudflare.com/workers/static-assets/routing/single-page-application/) xác nhận `single-page-application` fallback và mảng worker-first điều khiển rõ request vào Worker. [Wrangler configuration](https://developers.cloudflare.com/workers/wrangler/configuration/) xác nhận khai báo assets theo cấu hình; path local dùng `../web/dist` từ `apps/api/wrangler.toml`. [Headers](https://developers.cloudflare.com/workers/static-assets/headers/) xác nhận `_headers` là plain text blocks: pattern ở dòng đầu, header thụt vào các dòng sau; CSP đã áp dụng cho assets/index.
  - [Tailwind Vite](https://tailwindcss.com/docs/installation/using-vite) xác nhận plugin `@tailwindcss/vite` + `@import "tailwindcss"`; [theme](https://tailwindcss.com/docs/theme) xác nhận namespace `@theme` và `--color-*: initial` để loại màu mặc định. [React Router `RouterProvider`](https://api.reactrouter.com/v7/functions/react-router.RouterProvider.html) xác nhận DOM import từ `react-router/dom`; `createBrowserRouter` dùng từ `react-router`. [TanStack Query installation](https://tanstack.com/query/latest/docs/framework/react/installation) xác nhận `QueryClientProvider` với Query v5.
  - [Vite server proxy](https://vite.dev/config/server-options#server-proxy) xác nhận `headers` và `configure`; proxy đặt `Origin` ở cả hai điểm để ghi API luôn dùng `http://localhost:8787`. [Vite build options](https://vite.dev/config/build-options#build-assetsinlinelimit) xác nhận `assetsInlineLimit: 0` tắt inline data URI. [Fontsource introduction](https://fontsource.org/docs/getting-started/introduction) và [install](https://fontsource.org/docs/getting-started/install) xác nhận font package NPM tự host; Be Vietnam Pro/JetBrains Mono được import từ entrypoint. [Turbo configuration](https://turborepo.dev/docs/reference/configuration) xác nhận task phụ thuộc theo package dùng `@runway/api#build` → `@runway/web#build`.
