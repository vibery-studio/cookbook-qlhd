# C-06-003 · API vai trò

## Goal
`GET /roles` trả `{items, catalog}` đủ trường + `can`/`locked_reason` theo người gọi; `POST/PATCH/DELETE /roles` chạy đúng SPEC-06 §3.3 với mọi guard; người mang vai trò nhận quyền mới ở request kế tiếp.

## Context
SPEC-06 §3.3 (CAS + `db.batch`, stmt sau điều kiện `EXISTS(roles WHERE id=? AND version=?+1)`; 0 dòng → đọc lại phân loại 404/`stale`/403), §3.2 lỗi, FR-5 guard, FR-7, FR-8 (`role.created` · `role.updated` · `role.permissions_changed {added,removed}` · `role.deleted {name,label}`; target `role:<id>`), DEC-2 A (admin bất biến), DEC-4 B (TTL 60s). Quyền người gọi đọc **từ D1** (không principal cache). `grant_not_held`: `added ⊄ quyền actor` → 403 trước batch + lặp trong WHERE của INSERT. Mỗi 403 nghiệp vụ ghi 1 `permission.denied` (`metadata {rule, permission:"roles:write"}`), cùng kiểu FIX-03 `denyEscalation`. `name` vai trò mới = `"r_" + generateUlid().toLowerCase()`; ≤ 50 vai trò `is_system=0` → 409 `role-limit`. PLAN-06 R-5 (thứ tự `locked_reason`: admin > own_role > system; `admin_role` thắng `own_role`). RUNWAY: route giữ `c`, service không thấy `c`, DAO thuần, Problem+JSON. **Không đổi OpenAPI** (002 đã khóa); cần đổi → dừng, báo driver.

## Scope
In: file trong `touches`. Out: `/admin/users` (004), web (005/006), cắt lô >900 người (R-1, chỉ ghi doc).

## Steps
1. `domain/role-label.ts`: `normalizeLabel(s)` (NFC, trim, gộp khoảng trắng, `toLocaleLowerCase('vi')`) + test (khớp literal backfill 001).
2. `role-dao.ts`: list có `label,is_system,version,holders` (1 query + 1 query đếm gộp, không N+1), `listPermissionKeysForUser`/vai trò của actor từ D1.
3. `role-write-dao.ts`: stmt builder chưa chạy (CAS UPDATE/INSERT/DELETE có điều kiện, `holdersOf`, `userIdsOfRole`).
4. `role-admin-service.ts`: create/patch/delete → kết quả có kind; guard theo thứ tự `admin_role` → `system_role` (DELETE) → `own_role` → `grant_not_held`; sau commit `Promise.all(invalidatePrincipalCache)` cho người mang.
5. `roles.routes.ts`: handler thật, map kind → Problem.
6. `session-cache.ts` TTL mặc định 60; `docs/auth.md` max-time-to-revoke; `docs/rbac.md` mục xóa cache theo vai trò + R-1.
