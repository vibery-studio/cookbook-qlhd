# C-04b-001a · API — khách issued_*, list template_name/template_id, render SAMEORIGIN

## Goal
`Customer` có `issued_count` + `issued_total`; `ContractListItem` có `template_name`; `GET /contracts?template_id` lọc items + counts; `/contracts/{id}/render` trả `X-Frame-Options: SAMEORIGIN`.

## Context
SPEC-04b §3.2 (A)(B), §3.6 (R-1), FR-12, FR-2, FR-18, DEC-5, DEC-6. (A): luôn có mặt trên GET list / GET one / POST 201 / PATCH 200; `COUNT(*)` + `COALESCE(SUM(total),0)` chỉ `status='issued'`; `listCustomers` = 1 query danh sách + 1 query gộp `GROUP BY customer_id` với `IN (id của trang)` (không N+1). (B): JOIN `templates` trong cùng câu SQL danh sách; `countByStatus` thêm điều kiện `template_id` (vẫn trừ status); id lạ → rỗng (không 404), không ULID → 422 `validation`. R-1: một dòng ở `security-headers.ts` cho `RENDER_PATH` → `x-frame-options: SAMEORIGIN`; mọi route khác giữ `DENY`. Không sửa `apps/api/test/integration/contracts-4b-acceptance.test.ts`, `contracts-acceptance.test.ts`. Ghi nhớ: route giữ `c`, service không thấy `c`, DAO thuần `(db, input) → DTO`, race bằng CAS + `db.batch`, lỗi Problem+JSON. Xong thì `pnpm openapi:export && pnpm client:generate` cùng commit. KHÔNG chạy vitest song song với agent khác; driver chạy suite đầy đủ.
