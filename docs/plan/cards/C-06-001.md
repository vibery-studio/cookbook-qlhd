# C-06-001 · Dữ liệu vai trò + `roles:write` + nhật ký bất biến

## Goal
Bảng `roles` có `label`, `label_key` (UNIQUE), `is_system`, `version`, `created_at`, `updated_at`; 5 vai trò seed là hệ thống có nhãn Việt; quyền `roles:write` có trong catalog và được cấp cho `admin` + `giam_doc`. `audit_events` chỉ thêm được (D1 trigger từ chối UPDATE/DELETE); test dọn bảng qua MỘT helper chung.

## Context
SPEC-06 §3.1, FR-1, DEC-1 A, DEC-7 A. `name` không bao giờ đổi. Nhãn: admin "Quản trị hệ thống" · member "Thành viên (nền)" · giam_doc "Giám đốc" · quan_ly "Quản lý" · nhan_vien "Nhân viên". `label_key` = NFC + trim + gộp khoảng trắng + `toLocaleLowerCase('vi')` — backfill bằng literal chữ thường có dấu ("quản trị hệ thống", "thành viên (nền)", "giám đốc", "quản lý", "nhân viên"). Permission id `01PERM0000000ROLESWRITE00`. CLAUDE.md: `pnpm db:generate` chỉ sinh, không push; expand-only. PLAN-06 R-3/R-4/R-11.
FR-13 (SPEC-06 §0): trigger `trg_audit_events_no_update` / `trg_audit_events_no_delete` `BEFORE UPDATE|DELETE ON audit_events … RAISE(ABORT, 'audit_events is append-only: … refused')` — viết tay như `0012_template_versions_append_only.sql` (drizzle không theo dõi trigger). Helper `clearAuditEvents(db, where?)` trong `@runway/test-fixtures`: đọc `SELECT name, sql FROM sqlite_master WHERE type='trigger' AND tbl_name='audit_events'`, rồi MỘT `db.batch([DROP TRIGGER…, DELETE FROM audit_events [WHERE …], <sql gốc>…])` — không chép SQL trigger lần hai; tham số `db` kiểu cấu trúc tối thiểu (`prepare`/`batch`) vì package này `types: []`, không phụ thuộc workers-types. Bản cục bộ cùng logic đang ở `roles-acceptance.test.ts` — thay bằng import. `templates-acceptance` cần `where` (giữ dòng `template.created` seed). Card này **không chạy song song** với card/agent nào sửa các file test trong `touches` (FIX-03 phải commit trước — nó sở hữu `foundation-acceptance` + `fix-03-role-escalation` lúc lập PLAN).

## Scope

## Steps
1. `schema.ts` `roles`: `label text`, `labelKey text unique`, `isSystem integer notNull default 0`, `version integer notNull default 1`, `createdAt/updatedAt integer notNull default 0`.
2. `pnpm db:generate` → đọc `0016_*.sql`: phải là `ALTER TABLE roles ADD …` + `CREATE UNIQUE INDEX`; nếu drizzle dựng lại bảng (`__new_roles`, `DROP TABLE roles`) → dừng, viết tay ALTER (FK cascade `user_roles`/`role_permissions` sẽ mất dữ liệu), báo driver.
3. `0017_seed_roles_write.sql` (`INSERT OR IGNORE` / `UPDATE … WHERE name IN (…)`): backfill 5 vai trò (`is_system=1`, `label`, `label_key`, `created_at=updated_at=unixepoch()`); permission `roles:write`; grant admin + giam_doc.
4. `catalog.ts`: thêm `"roles:write"` đúng vị trí alphabet (policy.test kiểm thứ tự).
5. `docs/rbac.md`: `roles:write`, vai trò hệ thống vs tự tạo (`r_<ulid>`), `name` bất biến.
6. `0018_audit_events_append_only.sql` (2 trigger) + `docs/audit.md` một đoạn "append-only, chỉ test được dọn qua helper".
7. `packages/test-fixtures/src/audit.ts` + export; 9 file test: thay `DELETE FROM audit_events` / `"audit_events"` trong vòng lặp dọn bằng `clearAuditEvents(env.DB[, where])`.
