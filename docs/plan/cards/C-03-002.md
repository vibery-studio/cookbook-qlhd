# C-03-002 · Pure contract domain

## Goal
Every rule of SPEC-03 §3.2 as a pure, deterministic function (no db, no Hono, no `Date.now()` — time comes in as an argument), with unit tests.
The signatures below are the contract other cards code against; changing one = stop and tell the driver.

## Context
SPEC-03 §3.2 (sources, price, money half-up in bps, words with "lẻ" DEC-6, dates DEC-4/5, `requiredSteps` fail-closed, `eligibleAssignment`
distinct matching I9 + DEC-10, `canTransition`, `formatNumber`, render escape + `{{#if}}` + leftover placeholders). SPEC-02 §3.3–3.4 (field
shape, `source` strings, `default`, `field_rules`). Reuse `todayInVN` / `isValidIsoDate` from `utils/vn-date.ts` (read-only). SHA-256 via
`@noble/hashes/sha256` (already a dependency). Integers only — no float in money.

## Tests
- pricing: 2.700.000×1−500 = 2.565.000; 4.800.000×2−1500 = 8.160.000; half-up at .5 (e.g. 1.000.001 × 5000 bps); 10000 bps → 0.
- words: 2.565.000, 8.160.000, 105.000 ("lẻ"), 15/21/25 ("mười lăm", "hai mươi mốt", "hai mươi lăm"), 1.000.000.000, 0.
- dates: 2026-09-28+6 → 2027-03-27; +12 → 2027-09-27; 2026-08-31+6 → 2027-02-28; 2027-08-31+6 → 2028-02-29 (leap); seriesYear(2026-12-31T17:30Z) = 2027.
- policy: 500/1000 → 1 step; 1001/1500 → 2 steps ("Giám đốc duyệt", role giam_doc); missing var → 2 steps.
- assignment: 1 GĐ+1 QL, creator QL, 2 steps → fails naming "Giám đốc duyệt"; creator NV → ok; DEC-10 case (GĐ takes step 1 → step 2 blocked).
- merge/render: escape `<script>`; `{{#if so_bao_gia}}` dropped when empty; leftover `{{x}}` listed; draft shows "(chưa có số)" + "NHÁP".
- snapshot: missing chuc_vu → missing-fields [{key,label}]; whitespace = missing; so_bao_gia without ngay_bao_gia → invalid; DT14 → invalid naming ma_goi;
  ngay_bat_dau default = docDate; key `total` in values → invalid.
