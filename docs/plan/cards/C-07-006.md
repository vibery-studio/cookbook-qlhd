# C-07-006 · Rà soát quý

## Goal
Mỗi quý có đúng một đợt rà soát chụp người × vai trò (người `active`); Giám đốc Giữ/Gỡ từng dòng (không tự rà mình); dòng đổi giữa chừng tự đóng; quá 15 ngày thì báo.

## Context
SPEC-07 FR-7, FR-8, §3.1 (bảng), §3.3 "Rà soát", DEC-10..12; PLAN-07 §2b (hình dạng, `current`, `state`, thứ tự lỗi), R-11 (ai quyết dòng nào — chờ bạn duyệt).
- `review-period.ts`: `quarterOf(nowSeconds)` theo `Asia/Ho_Chi_Minh` (UTC+7, không DST) → `"YYYY-Qn"`; test: 2026-09-30T17:30Z → `2026-Q4`, 2026-12-31T17:30Z → `2027-Q1`, 2026-10-01T03:00Z → `2026-Q4`.
- Mở: một batch `INSERT access_reviews … ON CONFLICT(period) DO NOTHING RETURNING` → `INSERT access_review_items SELECT … FROM users u JOIN user_roles … WHERE u.status='active' AND u.deletion_requested_at IS NULL` (điều kiện review vừa tạo; "chưa xóa" = chưa yêu cầu xóa — SPEC §3.1) → audit `review.opened {period}`. 0 dòng → `duplicate`. `opened_by` = `"system:cron"` (cron) hoặc userId. `due_at = opened_at + 15 ngày`. `openQuarterReview(deps, now)` (stub 002) = nhánh cron (không lỗi khi đã có).
- Quyết: guard D1 (`jitActiveSql` của 001 → `jit_actor`; quyền theo R-11; `self_review`), `review-closed`, `item-changed` (vai trò hiện ≠ `role_name` hoặc user không `active`), rồi: Giữ = `UPDATE item SET decision … WHERE decision IS NULL OR …` + audit `review.item_decided {user, role, decision}`; Gỡ = `updateUser(deps, {actorId, userId, status:"disabled"})` (import, không sửa `user-admin-service.ts`; trả `forbidden admin_only` / `last-admin` nguyên) rồi ghi `decision` có điều kiện "user đã `disabled`" + audit. Mỗi 403 nghiệp vụ ghi 1 `permission.denied` (`metadata {rule, permission:"reviews:write"}`).
- Đóng: CAS `status='open' AND NOT EXISTS(dòng chưa quyết và chưa changed)` + audit `review.closed`.
- `current` + `overdue = status='open' AND now > due_at` + `progress`.
**Không đổi OpenAPI.**
