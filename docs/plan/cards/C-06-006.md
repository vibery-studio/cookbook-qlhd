# C-06-006 · Web Người dùng + nhãn vai trò

## Goal
Mời / đổi vai trò chọn được mọi vai trò (cả "Kế toán"); bảng người dùng, chip người dùng hiện `label` từ `GET /roles`, không hiện mã `r_…`.

## Context
SPEC-06 §3.4 "Người dùng": select từ `useRoles()` (`app/roles-query.ts`, C-06-005) — mời: trừ `admin`, `member`; đổi vai trò: trừ `member`; `admin` chỉ hiện khi người gọi là admin (DEC-5, FIX-03 đã có `role-locks.ts` — dùng lại). Nhãn: `roleLabelOf(name)`, fallback `name`; `me.tsx` bỏ map cứng `roleLabels` (hoặc giữ làm fallback khi `/roles` chưa tải). FR-12: vai trò mà quyền người gọi không bao trọn (so `/me` permissions với `permissions` của vai trò từ `GET /roles`; admin miễn) → option disabled + 🔒 "Bạn không có quyền này nên không cấp được" (gợi ý; API quyết); người đang mang vai trò như vậy → nút "Đổi vai trò" 🔒 cùng lý do. Câu lỗi `unknown-role` đã có ở `problem-messages.ts` (005) — không sửa file đó. Hợp đồng UI: dialog "Đổi vai trò · <tên>", select "Vai trò mới", option theo `label` (e2e `roles.spec.ts`).

## Scope
