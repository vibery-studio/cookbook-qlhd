## Context

**Chạy sau C-07-001 + C-07-002** (journal, catalog, `data-inventory.ts`, `roles-acceptance`). 2b merge sau mình / mình rebase sau 2b → `pnpm db:generate` lại, đổi số `0021/0022` cho khớp journal, giữ `0022` custom (`drizzle-kit generate --custom`).
Seed (bạn chốt): G3 1.350.000 (2025-01-01) → 1.500.000 (2026-01-01) · G6 2.400.000 (2025-01-01) → 2.700.000 (2026-07-01) · G12 4.500.000 (2025-01-01) → 4.800.000 (2026-01-01) — `service`, `month`, ĐVT "cửa hàng", KCT (`vat_rate_bps` NULL), tên giữ "Gói N tháng" · DT14 `service` `day` 14, 0đ KCT, `active=0` · `DEMO-MIN-01` "Máy in hóa đơn (DEMO)" cái 1.000.000 10% từ 2026-01-01 · `DEMO-GIAY-01` "Giấy in nhiệt (DEMO)" cuộn 20.000 10% từ 2026-01-01. Id = literal 26 ký tự cố định; `created_by` NULL (hệ thống). Quyền: id `01PERM000000PRODUCTWRITE00`, `01PERM00000000PRICEWRITE00`, grant cho `01ROLE00000000000GIAMDOC00` + `01ROLE000000000000QUANLY00`, `INSERT OR IGNORE`.
Trigger (thứ tự trong `0022`: quyền → seed → trigger): `BEFORE UPDATE ON product_prices` → RAISE(ABORT,'product_prices is append-only: UPDATE refused') · `BEFORE DELETE … WHEN OLD.effective_from <= date('now','+7 hours')` → 'product_prices: a price in effect cannot be deleted' · `BEFORE INSERT … WHEN NEW.effective_from < date('now','+7 hours') AND EXISTS (SELECT 1 FROM product_prices WHERE product_id = NEW.product_id)` → 'product_prices: backdated price refused'.
`created_by` TEXT không FK (như `contracts.created_by`). CLAUDE.md: `db:generate` chỉ sinh; expand-only.
