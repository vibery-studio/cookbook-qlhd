# C-07-005 · JIT

## Goal
Giám đốc cấp cho người khác quyền `admin` tạm (≤ 8 giờ, có lý do); trong thời hạn người nhận mang ĐÚNG quyền admin; hết hạn/thu hồi là mất ở request kế tiếp, không chờ cron hay TTL KV.

## Context
SPEC-07 FR-5, FR-6, §3.3 "JIT" + "Principal" + "Cron", DEC-5..8, §5; PLAN-07 §2b (thứ tự lỗi), R-3, R-7.
- Cấp: INSERT…SELECT CAS (user `active`, ≠ actor, không mang `admin` thường trực, `NOT jitActiveSql(user)`, actor không JIT) + audit `jit.granted {user, reason, expires_at}` cùng batch → `invalidatePrincipalCache(user)`. 0 dòng → phân loại. Idempotency qua `withIdempotency` (002 đã gắn).
- Thu hồi: `UPDATE … SET revoked_at, revoked_by WHERE id=? AND revoked_at IS NULL AND expires_at>now RETURNING` + audit `jit.revoked` + xóa cache người nhận. Người gọi: `jit:grant` thường trực (D1) hoặc chính người nhận; khác → 403 `forbidden` + denied.
- `sweepExpiredJit(deps, now)` (stub 002): `UPDATE … SET expiry_logged_at=now WHERE expires_at<=now AND revoked_at IS NULL AND expiry_logged_at IS NULL RETURNING` (≤100) → audit `jit.expired` + xóa cache.
- Principal: `loadPrincipal` miss → `findActiveJit` (jit-dao 001) → có thì `roles=["admin"]`, `permissions` = quyền của vai trò `admin` (D1); `CachedPrincipal.valid_until = min(now+TTL, jit.expires_at)` (không JIT: `now+TTL`); đọc cache: thiếu `valid_until` hoặc `now >= valid_until` → coi là miss (R-3). `listRoleNamesForUser` KHÔNG đổi (guard D1 không thấy JIT — DEC-7). Đồng hồ: `Date.now()` (test dùng `vi.setSystemTime`).
- `/me`: `jit: {expires_at} | null` từ `findActiveJit`.
- `docs/auth.md`: max-time-to-revoke cho JIT = 0 (cắt theo `valid_until`), KV TTL ≥ 60 (đọc lại developers.cloudflare.com/kv/api/write-key-value-pairs trước khi code).
`jitActiveSql`/`findActiveJit` của 001: không đổi chữ ký (004/006 import). **Không đổi OpenAPI.**
