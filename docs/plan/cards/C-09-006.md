# C-09-006 · Tạo / sửa / sao chép theo loại

## Goal
`POST /contracts` tạo đúng loại của mẫu (BG, HĐ, PXK; DNTT → 422 `parent-required`) với quyền lập của loại đó; sửa nháp con chỉ đổi trường tay (`lines-locked`); sao chép con bị từ chối/hủy giữ `parent_id` + giá đóng băng, chặn bởi `child-exists`/`quote-expired`.

## Context
SPEC-09 FR-1, FR-7, FR-12, FR-13, FR-14, §3.6 (`POST /contracts`, `PATCH`, `/copy`), DEC-4/5/6/10/14; PLAN-09 §2b, P-3, P-5, P-7, R-3, R-4.
- Gate (R-4, cùng commit route + service): route `POST /contracts` → `requireAuth` + `requirePerm("contract:read")` + `withIdempotency()`; `PATCH`/`DELETE` `/contracts/:id`, `/copy` → `contract:read`; service đọc loại (mẫu khi tạo, dòng khi sửa/xóa/sao chép) → thiếu `WRITE_PERM[type]` trong perms do route truyền → `{kind:"forbidden", permission}`; route ghi `permission.denied {permission, method, path}` (như `require-permission.ts`) rồi 403.
- Tạo: mẫu `type = payment_request` → 422 `parent-required` (trước dòng); `buildSnapshot({…, type})` (004); insert `type`, `valid_until` (BG = `snapshot.dates.valid_until`), `parent_id` NULL; audit `contract.created {to:"draft", type}`.
- Sửa: dòng có `parent_id` → body có `lines` hoặc `values.giam_gia` → 422 `lines-locked`; dựng lại bằng `buildChildSnapshot` từ snapshot cha đã lưu (không `resolveLines`) — đọc cha bằng hàm đọc có sẵn của `contract-read-dao` (002) hoặc thêm hàm đọc nhỏ trong `contract-write-dao`. `use_latest_template` chỉ đổi mẫu cùng loại (khác → `template-type`). Audit `contract.updated` + `type`.
- Sao chép: nguồn có `parent_id` → bản mới giữ `parent_id`, dựng `buildChildSnapshot` từ cha (giá đóng băng), `INSERT…SELECT WHERE EXISTS(cha issued [+ valid_until ≥ :today nếu cha BG])`; vi phạm `uq_contracts_parent_child_live` → 409 `child-exists` (+`existing_id`); 0 dòng → chẩn đoán `quote-expired`/`parent-not-issued`. Nguồn BG → giá hôm nay (như HĐ). Audit `contract.created` + `type` (+`parent_id`).
- `contract-write-dao.ts` chỉ card này. Không đổi OpenAPI (002 khai đủ); thấy thiếu → dừng, báo driver.
