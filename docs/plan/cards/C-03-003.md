# C-03-003 · OpenAPI contract (contract-first)

## Goal
All 13 endpoints of SPEC-03 §3.5 are in `/openapi.json` with their final guards and result → HTTP mapping; handlers call service stubs that answer
501; the generated client is up to date. After this card, wave-2 cards touch only their own service + DAO files.

## Context
SPEC-03 §3.5 (table + slugs), §3.3 (who), §5. Pattern: `routes/customers.routes.ts` (guards via `app.on(...)`, `withIdempotency()` on every POST,
`problem()` bodies). Services never see `c`: the route passes `{ actor: principal, ip, now: new Date() }` + validated input.

## Scope
In:
- `dto/contracts.ts`: `CreateContractBody` (`template_id`, `customer_id`, `values` = **strict** object of `ma_goi` string (not an enum: DT14 must reach the
  builder so the 422 names `ma_goi`), `so_cua_hang` int, `giam_gia` int 0–10000 optional, `chuc_vu_nguoi_ky` string, `ngay_bat_dau`/`ngay_bao_gia` ISO date
  optional, `so_bao_gia` optional); body `.strict()` (unknown → 422: `total`, `unit_price`, `number`, `status`…) · `UpdateContractBody`
  `{expected_version, customer_id?, values?, use_latest_template?}` strict · `RejectBody {note}` (trimmed, min 1) · `VoidBody {reason}` (trimmed, min 1) ·
  `ApproveBody {note?}` · `ContractSchema` (fields as the acceptance test's `Contract` interface: id, type, status, number, seq, series_year, template_id,
  template_version_id, customer_id, customer_name, total, created_by, doc_date, version, snapshot, snapshot_hash, source_contract_id, replaced_by_id,
  submitted_at, decided_at, issued_by, issued_at, rendered_hash, voided_by, voided_at, void_reason, created_at, updated_at, steps[], timeline[], can{7}) ·
  list query (`status` enum, `customer_id`, `created_by`, `cursor`, `limit` 1–50) + `ContractListResponse {items, next_cursor, counts{6}}` ·
  `ApprovalQueueResponse {items:[{contract_id, step_no, label, customer_name, total, created_by, created_by_name, submitted_at}], next_cursor}`.
- `dto/error.ts`: slugs `missing-fields`, `unresolved-placeholder`, `no-eligible-approver`, `state-conflict`, `changed-after-approval`,
  `would-block-later-step`; `ProblemDto` + `ProblemOptions` gain optional `missing_fields[{key,label}]`, `placeholders[]`, `step_no`, `label`,
  `current_status`, `rule`. Additive only (row 02 also edits this file — driver serializes).
- `routes/contracts.routes.ts` (12 endpoints) + `routes/approvals.routes.ts` (`GET /approvals/mine`) + mount in `routes/index.ts`. Guards:
  read = `contract:read`; POST/PATCH `/contracts` = `contract:write`; submit = `contract:submit`; approve/reject = `contract:approve`; issue/void =
  `contract:issue`; copy = `contract:write`; `/audit` = `audit:read`; queue = `contract:approve`. `withIdempotency()` on all 8 POSTs.
  `/render`: `text/html; charset=utf-8`, `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'`, `ETag: "<rendered_hash>"` when stored.
  403 SoD bodies carry `rule`; 409 `state-conflict` carries `current_status`. Detail strings in Vietnamese (SPEC §3.4), e.g. I9 detail verbatim from §3.3.
- `services/contract/*-service.ts`: one file per command with the FINAL signature + result union, body `throw new NotImplementedYet()`
  (`services/contract/not-implemented.ts`); routes' local `handle()` maps it to 501 Problem. Result unions (exact):
  - `create`: `ok{contract}` | `invalid{errors}` | `missing-fields{missing}` | `unresolved-placeholder{placeholders}` | `not-found{what:"customer"|"template"}`
  - `update`: `ok` | `not-found` | `forbidden` (not creator) | `state-conflict{current}` | `stale` | + create's 422 kinds
  - `copy`: `ok` | `not-found` | `state-conflict{current}` (source not rejected/voided, or voided already replaced) | create's 422 kinds
  - `submit`: `ok` | `not-found` | `forbidden` | `state-conflict{current}` | `no-eligible-approver{step}`
  - `decide` (approve|reject): `ok` | `not-found` | `forbidden-permission` | `sod{rule:"creator_cannot_approve"|"one_person_one_step"}` |
    `would-block-later-step{step}` | `state-conflict{current}`
  - `issue`: `ok` | `not-found` | `state-conflict{current}` | `changed-after-approval`; `void`: `ok` | `not-found` | `state-conflict{current}`
  - `read`: `list`, `detail`, `queue`, `contractAudit` (null → 404); `render`: `{html, etag|null}` | `not-found`
- `events/contract-events.ts`: `type ContractEvent = {name: "contract.created"|…|"contract.voided"; contract: ContractDto}`; `onContractEvent(fn)`,
  `emitContractEvent(evt): void` — calls each listener in try/catch, never throws; default listener logs `{kind:"event", name, id}` (no snapshot/PII).
- `pnpm client:generate`.
Out: DAOs, real service bodies.
