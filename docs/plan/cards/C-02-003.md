# C-02-003 · Seed migration + seed-check test

## Goal
Every environment (and every test DB) has the template "Hợp đồng cung cấp dịch vụ phần mềm" at v1 exactly as SPEC-02 §3.4/§3.5 says, with its `template.created` audit row (actor NULL); a test proves the seeded row passes the same `checkTemplate` used at write time.

## Context
DEC-5 (seed by migration), DEC-4 (Bên A + bank account live in the body), §3.5 (body verbatim, internal note removed), §3.4 (16 fields + `ma_goi`, `field_rules`, `approval_policy`), §3.1 (`created_by` NULL, audit actor NULL). Hand-written SQL via `pnpm db:generate --custom` (numbered "next" at build time; driver serializes the migrations folder with C-02-001). Fixed ULID literals (house convention, `0001_seed_rbac.sql`). Facts come only from SPEC/.docx — do not invent or reword any sentence; the reviewer diffs the body against §3.5.

## Scope
In: one migration: INSERT `templates` (`name_norm` = lowercase name), INSERT `template_versions` (v1: `body`, `fields`, `field_rules`, `default_line_items='[]'`, `default_clauses='[]'`, `approval_policy` JSON), UPDATE `templates.current_version_id`, INSERT `audit_events` (`action='template.created'`, `target='template:<id>'`, `actor` NULL, metadata `{"version_no":1,"fields":17}` — no body). Test `template-seed-check.test.ts`: read the seeded row through raw SQL, parse the JSON columns, assert `checkTemplate(...)` returns `[]` and the 16-key/17-field counts; assert `INSERT` of a version with the internal note appended fails the check (guards drift). Out: any route/DAO code, other templates, changes to the trigger migration.

## Steps
1. `pnpm db:generate --custom` → write the SQL (escape `'` as `''`; body is one string literal). 2. Test file. 3. `pnpm db:migrate:local`, inspect the row.

## Tests
`template-seed-check.test.ts` → the seed passes `checkTemplate`; a copy with "Ghi chú nội bộ …" appended fails with `internal_note`. AC-1/AC-2 acceptance covers the API view.

## Done check
- Command: `CI=true pnpm --filter @runway/api exec vitest run test/integration/template-seed-check.test.ts` → pass; `pnpm db:migrate:local` → `SELECT name, current_version_id FROM templates` shows 1 row; `SELECT version_no, length(body) FROM template_versions` shows v1
