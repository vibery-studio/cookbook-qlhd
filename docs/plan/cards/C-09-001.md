# C-09-001 · E1 dựng lại `contracts`

## Goal
Bảng `contracts` nhận 4 loại, có `parent_id`, `valid_until`, UNIQUE "một con sống mỗi (cha, loại)", giữ mọi dòng + mọi index cũ. Code cũ chạy y nguyên.

Giữ nguyên mọi CHECK/index cũ. Comment: `parent_id` = chuỗi nghiệp vụ (DEC-3), khác `source_contract_id` (sao chép).
